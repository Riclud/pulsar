# ИИ-агенты

ИИ-агент может собрать приложение на Pulsar и сам проверить свою работу: он запускает
приложение, смотрит на экран, прокликивает его и читает логи, пока правит код. Для этого
есть две вещи:

- **`pulsar mcp`** — сервер [Model Context Protocol](https://modelcontextprotocol.io),
  который даёт агенту инструменты, чтобы запускать приложение, видеть его и управлять им;
- **`pulsar skill`** — скилл, который учит агента самому Pulsar, чтобы он не искал по
  документации и GitHub.

По умолчанию приложение запускается без окна. Нажатия и клавиши уходят в окно приложения,
а не на вашу мышь и клавиатуру, так что вы можете работать, пока агент тестирует.

## Подключить MCP-сервер

Все клиенты запускают одну и ту же команду, `pulsar mcp`, через stdio.

**Claude Code**

```sh
claude mcp add pulsar -- pulsar mcp
```

**opencode:** выполните `opencode mcp add pulsar -- pulsar mcp` или добавьте в `opencode.jsonc`:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "pulsar": { "type": "local", "command": ["pulsar", "mcp"] },
    },
  },
}
```

**Cursor** (`.cursor/mcp.json`) и другие клиенты с форматом `mcpServers`:

```json
{
  "mcpServers": {
    "pulsar": { "command": "pulsar", "args": ["mcp"] }
  }
}
```

**Codex** (`~/.codex/config.toml`):

```toml
[mcp_servers.pulsar]
command = "pulsar"
args = ["mcp"]
```

## Поставить скилл

```sh
pulsar skill            # в .claude/skills/pulsar этого проекта
pulsar skill --global   # для всех проектов
pulsar skill --dir путь # куда угодно
```

В скилле короткий гайд: команды, манифест и разрешения, чего нет в QuickJS, модель UI и
состояния, частые ошибки. Рядом лежат проверенные рецепты, полный справочник API и гайды
по компонентам и вёрстке. Всё это берётся из установленного CLI, поэтому совпадает с его
версией.

`.claude/skills` читают Claude Code и opencode.

## Инструменты

| Инструмент | Что делает |
| --- | --- |
| `pulsar_start` | Запускает приложение с перезагрузкой на лету. `appDir` — папка, `visible: true` открывает настоящее окно. |
| `pulsar_stop` | Останавливает его. |
| `pulsar_ui` | Дерево интерфейса списком: тип, `#id`, текст, `[события]` и путь каждого узла. `json: true` отдаёт все свойства. |
| `pulsar_screenshot` | PNG окна после окончания анимаций (`settleMs`, по умолчанию 300). |
| `pulsar_click` | Настоящий клик мышью по узлу. |
| `pulsar_hover` | Наводит курсор на узел; `leave: true` уводит его из окна. |
| `pulsar_scroll` | Крутит колесо над узлом; `dy` в пикселях, 120 на щелчок. |
| `pulsar_type` | Вводит текст в поле с фокусом по клавише или задаёт значение поля через `into`. |
| `pulsar_key` | Клавиша с модификаторами: `enter`, `escape`, `tab`, `ctrl+s`, `shift+tab`. |
| `pulsar_back` | Событие «Назад» Android. |
| `pulsar_wait_for` | Ждёт, пока текст появится в дереве. |
| `pulsar_state` | Хранилище приложения (store). |
| `pulsar_eval` | Выполняет JS в приложении (для приложений на QuickJS). |
| `pulsar_logs` | Последний вывод: логи, ошибки и перезагрузки. |
| `pulsar_reload` | Перезапускает рантайм; окно остаётся. |

Инструменты находят узел по видимому тексту, по `a11yLabel` кнопки-иконки, по `path` или
`id` из `pulsar_ui` или по координатам `x` и `y` в окне. Давайте кнопкам-иконкам
`a11yLabel`: по нему их находит агент, и он же нужен экранным дикторам.

## Типичная сессия

1. `pulsar_start` с папкой приложения.
2. `pulsar_screenshot`, чтобы увидеть первый экран, и `pulsar_ui`, чтобы узнать, что можно
   нажать.
3. `pulsar_click` по «Новая задача», затем `pulsar_type` с `into: "Название"` и
   `pulsar_key` с `enter`.
4. `pulsar_wait_for` с новым названием, затем `pulsar_screenshot`, чтобы проверить результат.
5. После правки исходников приложение перезагружается само; ошибки сборки видны в
   `pulsar_logs`.

## Из терминала

То же управление работает без MCP, рядом с `pulsar dev`:

```sh
pulsar dev                  # в одном терминале
pulsar ui                   # в другом, из папки приложения
pulsar tap "Сохранить"
pulsar hover "Копировать"
pulsar scroll "Задачи" --dy 360
pulsar keys "молоко" && pulsar key enter
pulsar expect "молоко"
pulsar shot --out shot.png
```

На Android эти команды управляют сессией `pulsar dev --android` на телефоне.

## Ограничения

- Буфер обмена требует настоящего окна, поэтому без окна не проверить, что скопировалось.
  Смотрите на тост или в логи.
- `pulsar_eval` работает только на движке QuickJS; приложения с Bun или Node ответят ошибкой.
- `pulsar_start` запускает приложения для компьютера. Для телефона запустите
  `pulsar dev --android` сами. Тогда им управляют команды из терминала, а также
  MCP-инструменты с `appDir`.
- Кнопки, которые открывают браузер или файловый менеджер, по-настоящему откроют их на вашем
  рабочем столе.
